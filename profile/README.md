## Stickers em segundos pelo WhatsApp

O Pulbi transforma imagens e vídeos curtos em stickers prontos para usar diretamente pelo WhatsApp, sem precisar instalar outro aplicativo.

Esta organização reúne os projetos que fazem o Pulbi funcionar como website, bot, infraestrutura e ferramentas internas.
